# Perfume E-Commerce App UI
A modern and visually rich Perfume Shopping Mobile Application UI built using Flutter, focusing on premium design, smooth interactions, and a luxury shopping experience.

# Key Features
- Modern Flutter UI implementation
- Premium glassmorphism design system
- Smooth navigation flow (Onboarding → Product → Cart → Categories)
- Interactive product detail screen
- Elegant shopping cart & checkout UI
- Responsive and well-structured layout
- Gradient lighting and blur effects for depth
- Clean and reusable widget architecture
